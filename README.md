# ScreenStitch_Image-Stitcher

An application that takes images and stitches them together into a single panorama.

## Requirements

- Python 3
- [opencv-contrib-python](https://pypi.org/project/opencv-contrib-python/) `3.4.2.16` (the contrib build is required for the stitcher)
- PyQt5
- imutils
- numpy

Install with:

```
pip install -r requirements.txt
```

## Usage

1. Run `python screenstitch2.py`.
2. Click **Select Images** and pick two or more images.
3. Click **Generate Stitching**. The result is saved as `output.png` in the working directory and shown in the preview.
